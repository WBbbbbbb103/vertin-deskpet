# 手提箱来客 · 方案

状态：十三位已实装。首批四位是十四行诗、37、远旅、伊索尔德；后续加入了鹭鸶剪、梁月、蓝手帕、兔毛手袋、天使娜娜、塞梅尔维斯、洛伦兹蝴蝶、玛丽安娜和卡戎。后续角色按同一图片规格继续接入。

## 1. 定位

手提箱不是衣橱饰品，而是桌面上的**关键道具**。它永久留在维尔汀身边，点击后从箱中随机召唤一位角色，出现角色立绘、名字和一句短台词。

这个功能承担三件事：

1. 让“箱子”从背景设定变成可点击的桌面物件。
2. 给已有人物档案一个更轻的入口：不翻长档案，也能见到角色。
3. 为后续角色图片、语音和照片留档留出扩展位。

## 2. 解锁等级

实际采用 **Lv.5「箱中旅伴」** 解锁。

理由：

- Lv.5 已进入「箱中旅伴」阶段，适合开始认识箱子里的来客。
- 这样不需要等到后期才能见到首批四位角色；拍照和衣橱仍按后期等级展开。
- 后续角色可以继续在低等级加入，不影响主线陪伴节奏。

如果希望更早见到，可以改到 Lv.12；但不建议低于 Lv.10，否则会抢走早期衣橱和专注系统的注意力。

## 3. 桌面表现

### 未解锁

不显示手提箱，避免玩家看到一个点不动的道具。

### 解锁后

- 在角色右下方、旧行李箱旁边出现一只小手提箱。
- 尺寸约为角色的 1/4～1/3，不遮挡脸和快捷条。
- 鼠标移上去有轻微高光；点击时箱扣弹开，暖光从箱内露出。
- 召唤结束后手提箱合上，角色立绘从光里出现。

### 召唤动画

建议控制在 2.2 秒左右：

```text
点击箱子
→ 箱扣弹开（0.2s）
→ 暖光与纸屑（0.5s）
→ 角色从箱内升起（0.8s）
→ 名字和一句台词出现（0.7s）
```

支持 `prefers-reduced-motion`：减少动画时只做淡入和名字出现。

## 4. 召唤规则

### 基础规则

- 点击手提箱即可召唤。
- 每次召唤从当前角色池中随机抽取。
- 冷却 **1.2 秒**，防止连点导致立绘闪烁。
- 不消耗时之雨，不做付费抽卡。
- 已获得的角色可以再次出现，但会优先避开最近 2 次出现过的角色（当前角色池 13 人）。

### 新角色与重复角色

- 第一次召见：角色卡显示「初次来客」，亲密度 +2。
- 重复召见：显示「又见面了」，亲密度 +1。
- 每名角色首次召见后加入「箱中来客」收藏。
- 全部角色都见过后，手提箱仍可继续召唤，不再发新角色奖励。

### 收藏

新增「箱中来客」面板：

- 已见角色头像/名字。
- 未见过角色显示剪影和「？？」。
- 每张卡可打开对应人物档案（如果有）。
- 显示召见次数和最近一次时间。

## 5. 角色图片规格

用户稍后提供建模图片，按以下规格接入。

### 文件

- 格式：**PNG 或 WebP，透明背景**。
- 尺寸：建议 **1024 × 1536**，竖图；最小 800 × 1200。
- 构图：角色完整站在画面中，头部不要贴边，底部留 40–80px。
- 视角：统一 3/4 正面或正面，所有角色保持同一机位。
- 光影：统一光源方向；不要在图片里画桌面阴影。
- 不要带背景、文字、水印、边框。
- 如果是 3D 模型渲染，请用同一相机、同一焦距和同一站姿导出。

### 可选

- 缩略图：256 × 384，透明 PNG。
- 角色主题色：一个 HEX 值，用于名字卡和光效。
- 一句台词：中文 20–40 字，英文对应。
- 档案 ID：与 `renderer/js/dossiers*.js` 中的 id 对齐。

### 文件结构

```text
assets/characters/
  <id>.png
  <id>.thumb.png
  <id>.json        # 可选：主题色、锚点、缩放
```

### 数据格式

```js
{
  id: 'character-id',
  name: { zh: '角色名', en: 'Character Name' },
  title: { zh: '一句话身份', en: 'One-line title' },
  image: 'assets/characters/character-id.png',
  accent: '#8A7A9A',
  line: {
    zh: '从箱子里出来时，她先看了看桌面。',
    en: 'When she stepped out of the case, she looked at the desk first.',
  },
  dossierId: 'character-id',
}
```

## 6. 随机与状态

建议状态：

```js
state.summon = {
  seen: [],           // 已召见的角色 id
  counts: {},         // 每个角色召见次数
  lastIds: [],        // 最近 2 次，避免连续重复
  lastAt: 0,
  total: 0,
}
```

随机逻辑：

1. 从角色池排除最近 2 个 id。
2. 如果排除后为空，使用完整角色池。
3. 等概率抽取。
4. 记录 `lastIds`、`counts`、`seen`。

不做稀有度概率；角色池小的时候，稀有度会让某些角色几乎见不到。

## 7. 与现有系统的连接

### 人物档案

如果角色有 `dossierId`，角色卡显示「查看档案」，打开现有 `dossier` 面板。

### 相机与照片册

第二阶段可以加：

```text
召唤角色
→ 点相机
→ 照片记录里出现“与来客的合影”
```

第一版先不做，避免照片册的元数据模型膨胀。

### 陪伴记录

首次召见记录一条：

```text
箱中来客 · 角色名
```

不写入 DeepSeek 上下文，除非玩家主动在对话中提到该角色。

### 等级

Lv.5 解锁时，弹出一条特殊提示：

```text
箱扣响了一声。
Lv.5 · 箱中旅伴
新道具：手提箱
```

并在托盘/角色资料中保留入口。

## 8. 交互入口

- 桌面手提箱：主入口。
- 右键菜单「箱中来客」：打开收藏。
- 角色资料快捷按钮：可加「来客」。
- 不放进衣橱，不占手持槽。

## 9. 性能

- 角色图片按需加载，最多同时解码 2 张。
- 预加载当前角色池的前 5 张。
- 图片压缩到 1024×1536 以内；不要直接放 4K 渲染。
- 动画使用 Canvas/DOM，不引入新的 3D 引擎。

## 10. 验收标准

- 未到 Lv.5 时没有手提箱。
- 到 Lv.5 后手提箱出现在桌面上，点击有开箱动画。
- 每次召唤从池中随机，最近 2 次不会立即重复。
- 首次召见进入收藏并 +2 亲密度；重复 +1。
- 角色图片透明、不变形、在不同 DPI 下清晰。
- 角色卡能打开人物档案。
- 关闭再打开后收藏和次数保留。
- 减少动画模式下仍可完成召唤。

## 11. 需要你确认

1. 解锁等级已采用 **Lv.5**。
2. 当前采用 **1.2 秒冷却、不限次数**；如果希望每天一次免费，可以再改。
3. 角色池是只放你发来的建模角色，还是也允许从现有 148 位里选。
4. 每位角色是单张立绘，还是有表情/动作差分。
5. 首次召见 +2 亲密度、重复 +1 是否合适。

## 12. 收到图片后的接入顺序

1. 先收 1 张图，确认透明、比例、锚点和桌面缩放。
2. 建 `characters.data.js` 和 1 个角色卡。
3. 做手提箱 sprite 和开箱动画。
4. 做随机池、收藏面板、档案跳转。
5. 批量导入其余角色图，统一机位和缩放。
6. 再决定是否接照片册。
