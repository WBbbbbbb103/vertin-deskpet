# 音乐盒 · 方案稿

状态：**初版已实现**（桌面道具、面板、三首本地原创循环、音量/循环/睡眠定时）。专注联动仍留作下一步。

## 1. 定位

手提箱里的一只旧音乐盒。不是抽卡、不是每日任务，也不占用衣橱槽位。

它提供三件事：

- 一段可循环的桌面背景音乐。
- 一个和专注计时配合的“陪伴模式”。
- 一张由最后一张像素图作为封面的唱片/纸带视觉。

## 2. 入口与解锁

建议在 **Lv.8「旧日留声」** 解锁，低于相机（Lv.17）和箱侧合影（Lv.20），作为中前期的小奖励。

入口：

- 桌面手提箱旁增加一个很小的音乐盒道具，点击打开。
- 也可从「更多」菜单进入，避免桌面太挤。
- 不放进衣橱，不占手持槽。

## 3. 视觉

- 手提箱左侧放一只手掌大小的像素音乐盒。
- 盒盖内侧贴封面：使用最后一张“in the Rain”像素图，裁成方形，去掉右下角小红书水印。
- 打开时盒盖抬起，露出转动的纸带/发条钥匙。
- 播放时发条缓慢旋转，停止时回到静止。
- 保留 2D 像素风格，不做 3D。

封面参考：

`assets/music-box/cover.png`

## 4. 曲目

初版已放入 3 首本地原创纯音乐循环，总大小约 4.2 MB：

1. **雨落在箱上**：雨声 + 很轻的音乐盒单音，32 秒循环。
2. **翻页**：三拍子的音乐盒圆舞曲，31.5 秒循环。
3. **直到雨停**：氛围长音 + 稀疏音乐盒，34 秒循环。

约束：

- 不使用游戏原声、不放外部流媒体链接。
- 曲目来源必须是原创、已授权，或用户自己提供。
- 每首支持无缝循环；循环点不要有明显爆音。

## 5. 交互

面板打开后：

- 封面 + 曲名 + 当前播放时间。
- 播放 / 暂停。
- 上一首 / 下一首。
- 音量滑杆（独立于语音音量）。
- 循环开关，默认开。
- 睡眠定时：15 / 30 / 60 分钟 / 关闭。
- 关闭面板不停止播放；退出应用时停止。

不自动播放。首次打开只显示封面和“上发条”按钮。

## 6. 与专注计时联动（尚未实现）

可选开关「专注时播放」：

- 开始专注时，如果开关开启，音乐盒播放第一首。
- 进入短休/长休时自动切到第二首。
- 专注结束或暂停时淡出，不突然切断。
- 用户手动暂停音乐盒后，不因专注状态变化强行恢复。

不把音乐盒和奖励绑定，避免“为了奖励挂机听歌”。

## 7. 状态

建议新增：

```js
musicBox: {
  track: 'rain-on-the-case',
  volume: 0.35,
  loop: true,
  sleepMinutes: 0,
  playWithFocus: false,
  lastOpenedAt: 0,
}
```

不持久化“正在播放”，每次启动都从暂停开始。

## 8. 技术

- 优先使用 `HTMLAudioElement`，每首一个本地文件。
- 预加载当前曲目，切歌时保留 150–250ms 淡入淡出。
- 与现有 `PetAudio` 音效共用总音量上限，但音乐盒有独立滑杆。
- 支持 `prefers-reduced-motion`：发条不转，只保留播放状态。
- 不引入新的音频库。

## 9. 验收

- Lv.8 解锁后，桌面音乐盒出现。
- 点击打开面板，封面正确显示。
- 播放/暂停/切歌/循环/音量/睡眠定时可用。
- 关闭面板不中断；退出应用停止。
- 专注联动可关闭，默认关闭。
- 没有音频文件或文件损坏时显示“纸带卡住了”，不崩溃。

## 10. 暂不做

- 不做歌词同步。
- 不做在线曲库。
- 不做用户导入音乐（首版）。
- 不做音乐盒抽卡/付费。
- 不做 3D 旋转盒体。

## 11. 需要你确认

1. 解锁等级用 Lv.8 是否可以。
2. 三首曲目由你提供，还是先只做雨声 + 单音音乐盒。
3. 封面是整张方形图，还是裁成盒盖比例（建议 1:1）。
4. 音乐盒放在手提箱旁，还是只放在菜单里。
